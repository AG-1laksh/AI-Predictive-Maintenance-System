# Teacher Demo (Kafka + Spark + Predictive Maintenance)

## 1) Start broker
- Docker Redpanda is running on `localhost:9092`.

## 2) Start Spark streaming
Run:
- `./run_spark_stream.ps1`

What to show:
- Console batches with columns: `unit, cycle, RUL, failure, predicted_failure`.

## 3) Send live data to Kafka
Run in second terminal:
- `./run_kafka_producer.ps1`

What to show:
- Producer sends rows to topic `turbofan-fd001`.
- Spark console receives new batches.

## 4) Show stored streaming output
- Folder: `outputs/stream_predictions`
- Contains parquet files generated by Spark micro-batches.

## 5) One-line explanation
- "Kafka carries live sensor events, Spark consumes and scores them in streaming mode, and predictions are stored in parquet for downstream dashboards/analytics."
